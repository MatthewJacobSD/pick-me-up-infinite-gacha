### Key Game Mechanics Expanded

| Mechanic | Description |
|---|---|
| **Training** | Doesn't increase stats/level, but refines skill learning |
| **Intimacy Bonus** | Stats bonus when forming party with heroes you have goodwill with |
| **Skill Discovery** | Low-rank heroes have hidden talents found through training |
| **Hero Categorization** | Masters sort heroes by: 1) Mentality, 2) Skills, 3) Physical capability |
| **Daily Reset** | Food/daily necessities refill. Imagination-based items appear (no guns). |
| **Iselle's Restrictions** | Can only interfere in self-defence or when master's orders disobeyed |
| **Time Dilation** | Time flows differently in game world vs Earth |
| **Master Connection** | Pick Me Up interlocked with phone, can't be restarted |
