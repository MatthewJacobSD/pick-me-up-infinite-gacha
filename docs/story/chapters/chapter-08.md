### Key Game Mechanics Expanded

| Mechanic | Description |
|---|---|
| **Thinning** | Master sends disposable heroes to die in dungeons |
| **Role Assignment** | Non-combat jobs (cook, carpenter) based on real-world skills |
| **Cooking Skill** | Required to be assigned as cook |
| **Exclusive Weapons** | Heroes won't lose equipped weapons |
| **Combat Desire** | Heroes perform better when they want to fight |
| **Boss Floors** | Every 5 stages, difficulty spikes significantly |
| **Stat Growth** | Younger heroes grow faster (7-8 stat difference) |
| **Skill Plateau** | Some heroes get stuck at certain skill levels |
