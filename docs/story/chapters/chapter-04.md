### Key Game Mechanics Expanded

| Mechanic | Description |
|---|---|
| **Skill Leveling** | Skills improve through use (not stats) |
| **Skill Fusion** | Two skills can combine into a stronger skill (Lv.3) |
| **Pain Tolerance** | New skill gained from taking damage |
| **Time Dilation** | 3:1 ratio (game world : Earth). 1 day in game = 3 days Earth. |
| **Floor Replay** | Master can send heroes back to earlier floors for grinding |
| **Grinding Rewards** | Lower floors give less gold (1,000G vs 7,000G) |
| **Activity System** | disobedient heroes made to run circles to increase activity |
| **XP Distribution** | Only fighting heroes get experience points |
| **Star-Based Behaviour** | 1★ panic, 3★ fight immediately, higher ★ know they'll be summoned |
