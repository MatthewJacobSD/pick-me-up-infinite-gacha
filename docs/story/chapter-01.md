### Key Game Mechanics Revealed

| Mechanic | Description |
|---|---|
| **Star Rating** | Heroes have star ratings (1★, 2★, etc.) determining power |
| **Party System** | Drag and drop heroes into parties of 5 |
| **Tower Climbing** | Main dungeon challenge with floor progression |
| **Permadeath** | Heroes die permanently ("returned to goddess' embrace") |
| **Equipment Summons** | 10x summon system using gold (50,000 gold per 10x) |
| **Equipment Grades** | F, E-, E+, D+, etc. |
| **Fear Status** | Reduces all stats by 30% |
| **Subjugation Missions** | Annihilate all enemies to clear floor |
| **NPC Classes** | Novice, Hunter, Mercenary, etc. |
| **Stats** | Strength, Intelligence, HP, Agility |
| **Skills** | Level-based (e.g., Basic Swordsmanship Lv.1) |
