# Design Tasks

## 1. Visual Layout for the Main Screens

**Department:** Design
**Status:** Pending

### Objective
Create the visual identity and base layouts for the initial screens.

### Minimum Scope
- Title screen.
- Login screen.
- Main menu.
- Visual guide for buttons, colors, and hierarchy.
- Visual reference for the front-end team to follow without improvising.

### Minimum Validation
- Navigable prototype approved by the team.
- Check that the layout elements can be reproduced in the front-end without breaking.
- Visual validation with a consistency checklist.

### Done When
- The front-end has a clear visual guide to implement the screens.
