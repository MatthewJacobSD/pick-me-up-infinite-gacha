# Development Roadmap

> **Note:** This roadmap covers both engine implementations. Engine-specific tasks are in `v1/docs/tasks.md` and `v2/docs/tasks.md`.

## Stage 1: The Foundation

- Setup ASP.NET Core Project
- Implement Login/Auth
- Establish SignalR connection (Ping/Pong)

## Stage 2: The Sanctuary

- Implement Data Storage (Mock/JSON)
- Build Resource Generation logic
- Build Gacha logic

## Stage 3: The Tower (Combat)

- Build the combat simulator (start with Auto-battle only)
- Send logs to client
- Then add the "Intervention" capability

## Stage 4: The Crowd

- Add Matchmaking and Leaderboards
